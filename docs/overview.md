# Call Process

![Application Process](img/HowItWorks.png)

(1) Startups and SMEs can apply for price reductions on TEF-Health Services via the TEF-Health Platform [https://tef.charite.de](https://tef.charite.de) if (2) they fulfil all eligibility criteria (see below). (3) Following recommendations by independent reviewers, Startups and SMEs can (4) negotiate the terms of the Service Provisioning with the Service Providers.
